# soccer-scoreboard

サッカーのライブ配信（OBS のブラウザソースなど）で画面に重ねて表示する、スコアボードの Web ページです。
タイマーは配信者が手元で操作し、スコアは [API-FOOTBALL](https://www.api-football.com/) か [football-data.org](https://www.football-data.org/) のどちらか（メニューで選ぶ）から自動で取得します。取得が遅れたときのために、手動でスコアを直すこともできます。

HTML・CSS・JavaScript だけで動きます。football-data.org を使うときだけ、中継用の `fd.php`（PHP）が必要です。

## 主な機能

- **表示**: タイマー・前半/後半・スコア（チーム名は3文字表記。例: `FUL 1 - 0 HUL`）
- **配置の編集**: 3つのパーツをドラッグで移動・大きさ変更。「表示を整列」で中央にそろえる。画面の大きさが変わると同じ比率で拡大・縮小
- **試合中の操作（画面下部のバー）**: スタート・一時停止（1つのボタンで切り替え。止めた後は「再開」） / 後半開始 / ±1分・+5分 / 時間の直接入力 / スコアの +1・-1
- **試合の選択**: プレミアリーグ・ラ・リーガ・チャンピオンズリーグの試合を一覧から選ぶ（「これから24時間」または日付ごと）
- **使う API の選択**: メニューで「API-FOOTBALL」か「football-data」を選ぶ（選んだほうのキー欄だけ表示）
- **スコアの自動取得**: 自動同期を ON にすると、**タイマーが動いている間だけ**取得（API-FOOTBALL は80秒ごと、football-data.org は6秒ごと。ハーフタイムで一時停止すれば取得も止まる）
- **次の取得までのメーター**: 下部バーの右端の円が、次の取得まで少しずつ増えていく。中央に残り秒数（止めているときは「II」、取得中は「…」）
- **スコアが変わった時刻**: メニューに、API のスコアが変わった時刻とデータの更新時刻を最大8件表示（API の遅れを確かめる用）
- **表示の保存**: 位置・大きさ・チーム名・スコアなどはブラウザに保存され、再読み込みしても残る

## 使い方

1. `index.html` をWebサーバーに置くか、そのままブラウザで開く
2. 左上の三本線でメニューを開き、使う API を選んでキーを入力
3. 「試合を選ぶ」で試合を選び、「自動同期」を ON にする
4. キックオフと同時に下部の「スタート」を押す

OBS で使う場合は、ブラウザソースに `index.html` の URL を追加し、ソースを右クリック →「対話」から操作します。
配置や設定はブラウザごとに保存されるので、OBS の「対話」の中で一度配置を整えてください。

## API-FOOTBALL について

- 無料プラン（1日100回まで）で動くように作っています
  - 試合一覧: 1日分につき1回（「これから24時間」は2回）
  - チーム名の3文字表記: チームごとに初回のみ1回
  - 試合中のスコア: 80秒に1回（90分の試合でおよそ70〜80回）
- 1日の上限の2回手前で、自動同期を止めます
- **APIキーは、既定ではページを開いている間だけ使い、どこにも保存しません**（使う人がそれぞれ自分のキーを入力します）
  - メニューの「このブラウザにキーを保存する」をオンにしたときだけ、そのブラウザ（localStorage）に保存し、次に開いたときも入力済みになります。オフに戻すと削除します
  - 同じドメインの他のページからも読める場所なので、共用のパソコンや、他のサイトと同じドメインに置く場合はオフのままにしてください

## football-data.org について

- 無料プラン（1分10回まで・1日の上限なし）で、プレミアリーグ・ラ・リーガ・チャンピオンズリーグを使います
- 6秒ごとに取得します（1分10回の上限ちょうど）。上限に達したときは自動同期を止めずに、回数が戻るまで待ってから再開します
- **無料プランはスコアが遅れて届きます**（公式に分数の記載はありません）。メニューの「スコアが変わった時刻」で遅れを確かめられます
- API-FOOTBALL で選んだ試合でも、キックオフ時刻とチーム名で football-data.org の試合を探して取得します（逆はできないので選び直してください）
- football-data.org はブラウザから直接呼べない（CORS で許可されていない）ため、同じフォルダの `fd.php` が中継します
  - キーはページから `X-FD-Key` ヘッダーで受け取って転送するだけで、保存・記録はしません（URL に入れないのでアクセスログにも残りません）
  - 中継できるのは試合一覧（`matches`）と1試合（`matches/{id}`）だけ。同じサイトのページからの呼び出しだけ受け付けます
  - PHP 8 と curl 拡張が必要です
